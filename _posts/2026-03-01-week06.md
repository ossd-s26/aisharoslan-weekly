## AI for Project Evaluation

We used Claude Opus 4.6 for the AI evaluations. Overall, it did a pretty great job at finding and summarizing information, especially since our project, OpenFoodFacts, had 100+ repositories. It was still able to find the “main” repository and grab links from there. We found some weaknesses in terms of more specific information we needed like latest pull request/issues and how many people were on there. It linked to the overall issue page instead of the specific latest page and gave a range for the number of people in discussion instead of specifics. I think AI can be relied on for project evaluations if you need a general overview of the project and need a sense of whether it suits your needs or interests. However, if you need specific information like the latest code changes, then maybe manually evaluating it will be more accurate.
